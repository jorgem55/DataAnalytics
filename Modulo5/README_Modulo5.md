# m5_consultas_joins - Entrega Modulo 5 - Jorge Martinez
Ejemplos guiados: combinar consultas y limpiar columnas compatibles

## Contenido
1. Consulta 1 - Vista base del proyecto (INNER JOIN)
2. Consulta 2 - Clientes sin ventas (LEFT JOIN)
3. Consulta 3 - Productos sin ventas (LEFT JOIN)
4. Consulta 4 - Consolidado por canal (UNION ALL)

## Notas
El esquema de BD anterior no incluye territorios, segmento de cliente, region, fecha de registro ni canal de venta. Para poder resolver las consultas se agregan tablas, atributos y registros al modelo.

## Conclusión
En esta entrega aplicamos conceptos sobre consultas mas complejas en base de datos relacionales, a través de script SQL y utilizando repositorio de GitHub.
