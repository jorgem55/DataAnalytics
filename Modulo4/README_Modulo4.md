# m4_consultas_negocio - Entrega Modulo 4 - Jorge Martinez
Script SQL que contiene consultas a la base de datos ventas_Tech_Db

## Contenido
1. Consulta Resumen ejecutivo mensual, Total facturado, cantidad de pedidos y ticket promedio por mes.
2. Consulta Ranking de productos, top 5 por total facturado
3. Consulta Clientes recurrentes, Cantidad de pedidos y el total gastado, pedido > 1
4. Consulta Meses por encima/por debajo del promedio, total facturado por mes
Hallazgos/Comentarios

## Conclusión
En esta entrega aplicamos conceptos aprendidos sobre consultas en base de datos relacionales, a través de script SQL y utilizando repositorio de GitHub.
