# Martinez_Jorge_Checkpoint2_Mod8.pbix - Entrega Modulo 8 - Jorge Martinez
Modelo de datos con relaciones activas y tabla de medidas core en DAX

## Contenido
Basado en el M6 se realizan los 5 puntos requeridos:
1- Configurar el modelo de relaciones
2- Crear la tabla calendario
3- Crear la tabla de medidas
4- Crear las cinco medidas DAX
5- Validación con Matriz

## Conclusión
En esta entrega aplicamos los nuevos conceptos a través de Power BI, configuracion del diagrama de relaciones, tabla calendario (de fechas), columnas calculadas, CALCULATE, VAR-RETURN, tabla de medidas DAX y validación con una matriz.
